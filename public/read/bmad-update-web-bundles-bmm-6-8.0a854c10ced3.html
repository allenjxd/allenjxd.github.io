乔木改写

Brian Madison 在 The BMad Code 的更新里写道：七周里，BMad Method 发布了 7 个版本（v6.3 到 v6.8），BMad Builder 发布了 4 个版本，Test Architect 发布了 7 个版本，并且给不住在 IDE 里的人开了一扇新的前门。

当天上线的 Web Bundles v1.0.0

入口在 bmadcode.com/web-bundles。BMad 的规划技能被打包成 Google Gemini Gems 和 ChatGPT Custom GPTs。首发货架上有六套：

  • Brainstorming Coach、Product Brief Coach、PRFAQ Coach、PRD Coach、UX Coach、Market & Industry Research

每套的设置只要几分钟：下载、解压、创建 Gem 或 GPT，再按其中的步骤做完。不需要 IDE，不需要命令行，也不需要写代码。

他特别写了两点。

第一，这是给非技术同事和工程师一起用的。创始人、产品经理、设计师和运营人员可以进入 BMad 的生命周期，而不必先学会一个编辑器。已经在 IDE 里跑 BMad 的工程师则能省一笔费用：把规划放在按固定费率计费的 Gemini Advanced 或 ChatGPT Plus 订阅上，把 IDE 预算留给代码库工作。

第二，它和 IDE 技能保持完整的 schema 对齐。可以在 Gem 里开始，把产物交给在 Claude Code 里工作的工程侧，下周再回到 Gem 里修改，过程不会断掉。

关于设计和 SDLC 故事，他说明还会另写一篇独立文章。

BMad Method 从 v6.3 走到 v6.8

这 7 个版本的主线，是新一代规划技能，也标出了平台其余部分将往哪里走。

  • bmad-prd 和 bmad-brief 被重写（v6.7.0）：提供创建、更新、校验三种意图，有 Fast 和 Coaching 两种模式，输出会按规模调整，可通过 customize.toml 完全控制，并用质量量表做校验。bmad-prd 现在是唯一的 PRD 技能，被弃用的 PRD 技能会转到它。
  • 新的核心技能 bmad-spec（v6.8.0）：把任意输入（头脑倾倒、PRD、逐字稿、简报）提炼成五字段的 SPEC.md 内核，方便给后续的架构、故事和开发技能使用。它取代了 bmad-distillator。
  • bmad-ux 全面改版（v6.8.0，含破坏性变更）：取代 bmad-create-ux-design。输出分成两条脊梁：DESIGN.md（Google Labs 规格）和 EXPERIENCE.md。其中包括具名主角的旅程、向 Stitch 交接，以及可选的审查关卡。
  • bmad-investigate（v6.7.0）：用带证据分级的法医式案卷，做缺陷分诊、根因分析和陌生代码探索。
  • 19 种新的引导技术和 framing 类别（v6.8.0）：包括六顶思考帽、Delphi、Steelmanning、Abstraction Laddering 等。资料库从 50 种增加到 69 种。
  • 23 个以上技能的激活护栏被加固（v6.8.0）：补上了 LLM 跳过追加步骤、并让 on_complete 钩子静默失败的那类缺陷。
  • 所有内容都可用 TOML 定制（v6.4.0）：每个 Agent 和工作流都可通过 _bmad/custom/ 定制，不必 fork。配套的 bmad-customize 技能会带着走完流程。
  • 发布通道：stable / next / pinned（v6.4.0）：按模块划分，可交互切换，也可用命令行参数切换。
  • 新增 18 个 Agent 平台（v6.5.0）：合计支持 42 个。新增包括 Sourcegraph Amp、IBM Bob、Warp、OpenHands、Replit Agent 等。
  • 非交互安装器（v6.6.0）：--set 和 --list-options 参数让 BMad 更适合 CI 和 Docker。
  • .decision-log 模式（v6.7.0）：跨会话跟踪工作流决策，便于干净地继续，也便于审计。

完整变更记录在 BMM changelog。

BMad Builder、Test Architect 和 Creative Intelligence Suite

BMad Builder 从 v1.6 走到 v1.8.1，主要包括：给模块作者的 customize.toml（v1.6.0），与 BMM v6.4 同一套框架；用于发布前评估技能的 bmad-eval-runner（v1.8.0），带隔离、依赖预备和完整文档；工作流构建器的改版（v1.8.0），合并了扫描器，校验反馈也更清楚；以及带 App 认证和 cosign 签名的发布流水线（v1.7.0），用于模块分发的供应链完整性。完整记录在 BMB changelog。

Test Architect 从 v1.15 走到 v1.19。v1.18.0 增加了审计置信分，让审查者知道哪些发现更值得采信。目录也做了规范化：13 列 schema，preceded-by / followed-by 的重命名，以及 knowledge-index 的范围限定。完整记录在 TEA 发布说明。

Creative Intelligence Suite 到了 v0.2。v0.2.0 引入了 customize.toml 和 Agent 名册，CIS 采用同一套框架，并提供简体中文文档。

国际化方面，zh-CN、vi-VN、fr-FR 和 cs-CZ 做了同步和刷新，BMad Ecosystem 侧边栏在这四种语言里都已本地化。

下一步计划

更新文还列出了接下来要做的事：

  • 全栈技能的简化：架构、故事创建、工单、开发、代码审查将采用 bmad-prd / bmad-brief / bmad-ux 的模板，SPEC.md 与 DESIGN.md / EXPERIENCE.md 成为正式输入。
  • 更多分析技能：发现访谈、顾客旅程图、机会规模估计、竞品拆解。
  • bmad-automator（next 通道）：把规划产物变成可执行的工作。安装方式是 npx bmad-method install，然后选择 BMad Automator。
  • bmad-method-ui（社区 alpha）：VS Code 仪表盘，以及独立的 Next.js Web 仪表盘，代码在 github.com/bmad-code-org/bmad-method-ui。
  • Web Bundles 货架还会继续增加，订阅 bmadcode.com 可收到提醒。

BMad Update: Web Bundles for Gemini & ChatGPT, plus BMM v6.8.0

Seven weeks, seven BMad Method releases (v6.3 → v6.8), four BMad Builder releases, seven Test Architect releases, and one new front door for everyone who does not live in an IDE.

🚀 Web Bundles v1.0.0 (today)

bmadcode.com/web-bundles: BMad planning skills, packaged as Google Gemini Gems and ChatGPT Custom GPTs. Six bundles in the launch shelf:

  • Brainstorming Coach, Product Brief Coach, PRFAQ Coach, PRD Coach, UX Coach, Market & Industry Research

Setup is a few minutes per bundle (download, unzip, create the Gem or GPT, follow the inline steps). No IDE, no CLI, no code.

Two things worth calling out:

  • Built for non-technicals AND engineers. Founders, PMs, designers, and ops staff get into the BMad lifecycle without learning an editor. Engineers running BMad in an IDE get a serious cost saver: planning on a flat-rate Gemini Advanced or ChatGPT Plus subscription, IDE budget reserved for codebase work.
  • Full schema parity with the IDE skills. Start in a Gem, hand the artifacts to engineering in Claude Code, refine in a Gem next week. Nothing breaks.

Deeper write-up on the design and the SDLC story is coming as a standalone post.

📐 BMad Method v6.3 → v6.8

Seven releases. The throughline: a new generation of planning skills that defines where the rest of the platform is headed.

  • bmad-prd and bmad-brief, rewritten (v6.7.0): Create / Update / Validate intents, Fast and Coaching modes, scale-adaptive output, full customize.toml control, quality-rubric validation. bmad-prd is now the single PRD skill; deprecated PRD skills route to it.
  • bmad-spec, new core skill (v6.8.0): Distills any input (brain dump, PRD, transcript, brief) into a five-field SPEC.md kernel. Optimized for downstream consumption by architecture, story, and dev skills. Supersedes bmad-distillator.
  • bmad-ux total overhaul (v6.8.0, breaking): Replaces bmad-create-ux-design. Two-spine output: DESIGN.md (Google Labs spec) + EXPERIENCE.md. Named-protagonist journeys, Stitch handoff, opt-in reviewer gate.
  • bmad-investigate (v6.7.0): Forensic case files with evidence-graded findings for bug triage, RCA, and unfamiliar-code exploration.
  • 19 new elicitation techniques + framing category (v6.8.0): Six Thinking Hats, Delphi, Steelmanning, Abstraction Laddering, and more. Library grows from 50 to 69.
  • Activation guardrails hardened across 23+ skills (v6.8.0): Closes the bug class where LLMs skipped append steps and on_complete hooks silently.
  • TOML customization for everything (v6.4.0): Every agent and workflow customizable via _bmad/custom/ without forking. Companion bmad-customize skill walks you through it.
  • Release channels: stable / next / pinned (v6.4.0): Per-module, switchable interactively or via CLI flags.
  • 18 new agent platforms (v6.5.0): 42 supported total. Sourcegraph Amp, IBM Bob, Warp, OpenHands, Replit Agent, and more.
  • Non-interactive installer (v6.6.0): --set and --list-options flags make BMad CI/Docker-friendly.
  • .decision-log pattern (v6.7.0): Workflow decisions tracked across sessions for clean continuations and audits.
